# AgentTeams DSH Runtime status

Date: 2026-08-25  
Target: GOAI Agent Infra semi-final and the long-term JUCHANG runtime

## Decision

The competition path no longer uses QwenPaw. AgentTeams remains the sole authority for identity, Matrix rooms, Project/DAG state, Taskflow, result acceptance and human intervention. DSH runs the Manager, Team Leader and four domain Workers. Deep Agents remains optional for Evidence Guard tasks that cross the explicit deterministic complexity threshold.

The DSH Manager and DSH Team Leader remain separate. Manager performs Controller-level Worker/Team administration with expiring human-confirmed plans; Team Leader performs Project/DAG coordination through TeamHarness and cannot administer cluster resources.

## Implemented and verified locally

- Independent Apache-2.0 package with no QwenPaw dependency.
- AgentTeams `MemberRuntimeConfig` validation, Matrix identity and path confinement.
- Worker flow: exact mention → official TeamHarness `ack_task` → DSH Headless → zero-write receipt → official `submit_task` → exact Team Leader mention.
- Failure flow submits authoritative `BLOCKED` instead of falling back to chat text or model guessing.
- Team Leader flow: fixed four-role DAG, ready-node-only delegation, `check_task.effective=true` gate, receipt validation, `accept_task_result`, terminal readback, aggregate DSH summary, guarded `complete_project`, terminal readback and `READY_FOR_HUMAN_REVIEW`.
- Generic DSH Manager with exact Admin/DM binding, Controller response redaction, read-only direct queries, expiring confirmations, destructive confirmation suffix and execute-once plan state.
- QwenPaw-free Dockerfile containing DSH `0.1.1-rc.2`, Python 3.12, MinIO Client, Deep Agents ACP and the official AgentTeams v1.2.3 TeamHarness MCP.
- Version-locked AgentTeams v1.2.3 Manager/Worker patcher adds `dsh` runtime recognition, Manager DM room injection and credential-bearing Worker `runtime.yaml`; Team updates merge roster context without erasing credentials.
- Patched official Go packages passed: `internal/backend`, `internal/controller`, `internal/service`, and `cmd/agt`.
- CloudStudio manifests define one DSH Manager, one DSH Team Leader and four DSH Workers using `MiniMax-M3`.
- Optional Deep Agents 0.7.6 / deepagents-acp 0.0.8 compile self-check and real ACP transport smoke passed (`DEEPAGENTS_ACP_READY`).
- Editor projection converts an audited terminal project into the existing Material Processing workbench format; editor copy stays business-facing.
- Runtime tests: 19/19 passed.
- Official TeamHarness probe: `OFFICIAL_TEAMHARNESS_READY` against AgentTeams v1.2.3 `server.py`.
- Main project: `npm run check`, `npm run validate:data`, `npm run gate`, and `npm run loop` passed after the required ModelScope SDK became readable in the authorized environment.
